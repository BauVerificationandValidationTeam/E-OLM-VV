## 7.3 Future Work

The following items propose potential improvements that were not implemented due to project scope and time constraints.

| ID | Proposal | Priority | Description |
|----|----------|----------|-------------|
| FW-01 | Advanced CI/CD Pipeline Integration | High | Extend the existing security-scan workflow to a fully automated CI/CD pipeline where regression tests, static analysis, and security scans are executed automatically on every code push. |
| FW-02 | Mutation Testing & High Coverage | High | Increase code coverage to above 90% and apply mutation testing techniques to evaluate the effectiveness of the test suite and detect insufficient test assertions. |
| FW-03 | Performance & Load Testing | Medium | Evaluate system behavior under high user load using tools such as JMeter or Locust. This includes testing response times, throughput, and system stability under stress conditions. |
| FW-04 | Full-Scale Model Checking | Medium | Move beyond lightweight formal verification by applying full-scale model checking techniques to critical modules in order to mathematically verify system correctness. |
| FW-05 | Usability & User Acceptance Testing | Low | Conduct usability and user acceptance testing with real users to validate user interface design, interaction flows, and overall user satisfaction. |

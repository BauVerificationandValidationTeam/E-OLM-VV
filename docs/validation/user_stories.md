Student User Stories
US-01 – Student Registration

As a student
I want to create an account
So that I can access the online library system.

US-02 – Student Login

As a student
I want to log into the system using my credentials
So that I can view and manage my library activities.

US-03 – View Available Books

As a student
I want to view a list of available books
So that I can choose books to borrow.

US-04 – Borrow a Book

As a student
I want to borrow an available book
So that I can read it for a limited period.

US-05 – Renew Borrowed Book

As a student
I want to renew a borrowed book
So that I can extend the return deadline if the book is not reserved.

US-06 – Return Book

As a student
I want to return a borrowed book
So that it becomes available for other users.

US-07 – View Issued Books

As a student
I want to see the list of books I have borrowed
So that I can track due dates and status.

US-08 – Update Profile

As a student
I want to update my profile information and password
So that my account remains secure and up to date.

Admin User Stories
US-09 – Admin Login

As an admin
I want to log into the admin panel
So that I can manage the library system.

US-10 – Manage Books

As an admin
I want to add, update, or delete books
So that the library catalog remains accurate.

US-11 – Manage Authors and Categories

As an admin
I want to manage authors and categories
So that books are properly classified.

US-12 – Issue Book to Student

As an admin
I want to issue books to students
So that borrowing transactions are controlled by the system

Assumptions

The system uses a single centralized database.

User roles are limited to Student and Admin.

A student can borrow only a limited number of books at the same time.

The system is accessed through a web browser (web-based).

Authentication is handled using Django’s built-in authentication mechanism.

Constraints

Due to time limitations, only core functionalities have been tested.

Performance and load testing are out of scope.

Security testing is limited to basic checks.

No external payment, email, or notification services are integrated.

All tests were conducted in a local development environment.
